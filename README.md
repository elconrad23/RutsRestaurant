# Rutz Restaurant Landing Page

Modern restaurant landing page scaffold with a sidebar navigation experience.

## Files

- `index.html` — main landing page structure
- `styles.css` — responsive layout and modern sidebar design
- `script.js` — simple navigation highlight behavior
- `images/logo.png` — restaurant logo asset
- `images/hero.jpg` — hero dish or lounge image asset

## Setup

1. Add the provided logo image to `images/logo.png`
2. Add the hero image to `images/hero.jpg`
3. Open `index.html` in your browser to preview

## Notes

This project is initialized as a Git repository and ready for extension.
